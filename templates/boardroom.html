How it works

Frontier models, distinct roles.

Five directors run in parallel. Each one is a different frontier model, prompted to inhabit a specific board-level role. Claude leads on long-range strategy. GPT-5 runs the operator's brief. Gemini handles capital and unit economics. Grok plays the skeptic — finding what the room is missing. Perplexity grounds the discussion in current data.

The Chair synthesizes. Once the directors have spoken, a final Claude Opus call reads all five responses, identifies where the board agrees and disagrees, and delivers a clear recommendation. No hedging.

You stay in control. You decide which directors are at the table by setting their API keys. Each meeting costs $0.10–0.30 in API fees. No hidden surcharge from us.
